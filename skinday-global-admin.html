Crawl clinic websites for doctors
Works through the 707 single-site clinic domains, a few at a time. Reads names and titles from each clinic's own team page — no API key and no per-page cost. Names go live immediately: a clinic listing its own doctors publicly is public information, and we are republishing it rather than vouching for it. Corrections come from clinics and doctors contacting us. Chains and social-only sites are excluded from the queue. Leave the tab open while it runs; press Stop any time.
Crawl clinic websites for contacts
Reads each clinic's own site for its official Facebook page, Instagram profile and LINE account, a few domains at a time. Covers the 701 single-site domains from the doctor crawl plus the chain domains, which were only ever excluded because a doctor cannot be attributed to a branch. Contacts found on a chain's site are applied to every branch on that domain. Tracked on its own status, so the doctor run's history is untouched, chains stay invisible to the doctor crawl, and either pass can be re-run independently. A link on a clinic's own site IS that clinic's official account, which is why nothing is ever taken from search results or beauty aggregators. LINE is often written as bare text rather than a link (官方LINE：@abc123), so text is read as well as links. Existing contacts are never overwritten: only an empty field is filled. A handle that turns up on 3 or more other clinics is treated as a shared plugin and rejected. Leave the tab open while it runs; press Stop any time.

Device crawl
Reads each clinic's own website for the aesthetic devices they run, matched against the curated reference list. Nothing here is visible to patients: candidates sit in a table the public key cannot read, and only approving one publishes a device.
Country
The queue holds every country. Choosing one here scopes the crawl, the retry and the counts, so a US run can never drain Canada's queue.
Run
Crawls one site now and shows exactly what it read, whatever its queue status or country.
This only advances while the tab is open and awake, so do not run it alongside another crawl. Watch the first ten hosts before leaving it to loop. Each device shows how it was found: own page means the clinic has a dedicated page for that machine, which is the strongest evidence; named means it was written in the page text; blog means it appeared in an article and may be a device they only wrote about.
Review candidates
Approving publishes the device on the clinic, marked as listed rather than verified, and dates it to the day the page was read. A newly published device also writes an entry to the change feed, which is what a manufacturer subscribes to.
Unmatched names
Capitalised names that sat next to a device word on a clinic page and matched nothing in the reference list. This is how the real long tail gets found. Anything appearing on several hosts is probably a machine worth adding to the list.
